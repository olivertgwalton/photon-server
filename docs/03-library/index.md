---
title: "Build your library"
summary: "How photon-server turns folders of films and shows into a library, and keeps it described and up to date."
---

A library is a folder on the server that photon-server reads films, shows or both from. The server
walks the folder, reads each file's name for what it is, matches the title to the metadata
providers you choose, and keeps watching the folder for what you add, rename or remove. This
section takes you from a folder of files to a described, curated library: how to lay the files out,
how to add the library, where its descriptions and pictures come from, how to correct a title the
server got wrong, and the extras that hang off a title, from collections to theme music.
